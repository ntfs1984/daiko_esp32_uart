# daiko_esp32_uart
Управление кондиционерами Daiko при помощи модуля на ESP32 и простых HTTP GET запросов.

В кондиционерах Daiko используются небольшие модули, подключаемые по UART, чаще всего выводимый в USB-A разъем: JUZ6.672.10198
Чтобы управлять кондиционером без облаков, нам потребуется копеечный модуль ESP32, и два резистора на 1кОм и 2кОм.

Использовать мы будем пин 4 в качестве RX, и пин 5 в качестве TX.
Внимание: UART кондиционера использует 5В в качестве логической единицы, поэтому во избежания мусора и деградации МК, лучше использовать конвертер уровней или примитивный резистивный делитель на пине 4 (который принимает сигнал TX от платы кондиционера)

[ Плата кондиционера ]               [ ESP32-C3 MINI ]
      +5V (USB Pin 1) ----------------------> 5V / VIN
      GND (USB Pin 4) ----------+-----------> GND
                                |
      TX (USB D-) ----[ 1k ]----+-----------> GPIO_RX (у нас это пин 4)
                                |
                             [ 2k ]
                                |
                               GND
                               
      RX (USB D+) <-------------------------> GPIO_TX (у нас это пин 5)
